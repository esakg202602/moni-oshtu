# Campus Vision — контроль занятий по камере

Камера в браузере узнаёт студентов и преподавателей, фиксирует опоздания и то, что человек делает
(смотрит вперёд, ПК, тетрадь, телефон, отвернулся, лежит, стоит, у доски), и пишет всё в Supabase.
Баллы (рейтинг и модуль) списываются по правилам, которые вы настраиваете в разделе «Правила».

Все файлы лежат в одной папке без подпапок — их можно загрузить на GitHub обычным выбором файлов.

## 1. Supabase (база данных)
1. supabase.com → New project.
2. SQL Editor → вставьте весь файл `schema.sql` → Run.
3. Project Settings → API: скопируйте **Project URL** и **service_role key** (секретный ключ, никому не показывать).

## 2. GitHub (без папок)
1. github.com → New repository (Private) → Create.
2. «uploading an existing file» → выделите **все файлы из папки campus-vision** (Ctrl+A) и перетащите в окно.
   Нужны файлы: `server.js`, `package.json`, `index.html`, `app.js`, `styles.css`, `schema.sql`, `render.yaml`, `README.md`.
3. Commit changes.

## 3. Render (запуск)
1. render.com → New → Web Service → выберите репозиторий.
2. Build Command: `npm install` · Start Command: `npm start`.
3. Environment Variables:
   - `SUPABASE_URL` — Project URL
   - `SUPABASE_SERVICE_KEY` — service_role key
   - `ADMIN_PASSWORD` — ваш пароль для входа
   - `SESSION_SECRET` — любая длинная случайная строка
   - `INTEGRATION_KEY` — ключ для подключения университетской системы баллов
   - `TZ_OFFSET_H` — `6` (Бишкек)
4. Deploy. Откройте выданный адрес `https://….onrender.com` (HTTPS нужен для камеры).

## 4. Первый запуск
1. **Люди** → «Импорт списком» (ФИО; телефон) → поставьте галочку согласия на биометрию («Изменить»).
2. «Из фото» — загрузите паспортное фото человека, и/или «Обучить по камере» (≈15 сек, заодно запоминается цвет формы и свет).
3. **Занятия** → создайте занятие (группа, преподаватель, время, допустимое опоздание).
4. **Камера** → выберите занятие → Старт. «Калибровка» — порог наклона головы и зона доски.
5. **Проверка** — нарушения, ожидающие решения человека. **Отчёты** — по каждому человеку, экспорт CSV.
6. «Завершить занятие» — не пришедшие отмечаются отсутствующими.

## Подключение университетской системы баллов (позже)
`GET /api/integration/points` с заголовком `x-api-key: <INTEGRATION_KEY>` — отдаёт `external_id`, рейтинг и модуль каждого студента.

## Что важно знать
- Видео не передаётся на сервер: распознавание идёт в браузере компьютера аудитории, на сервер уходят только события.
- Камера: веб-камера, USB или телефон через DroidCam/Iriun/OBS Virtual Camera. RTSP напрямую браузер не читает.
- Точность зависит от камеры: лица дальше ~6–7 метров распознаются плохо — ставьте камеру спереди, на уровне доски, и выбирайте «Точность лиц» 512–608.
- Позы и предметы определяются эвристиками (порог наклона головы, телефон рядом с руками). Поэтому поведенческие нарушения по умолчанию идут на проверку человеком, а опоздание и отсутствие применяются автоматически. Это переключается в «Правилах» (галочка «Авто»).
- Закройте занятие кнопкой «Завершить» — только так сохранятся последние состояния.
- Биометрия — особая категория персональных данных. Получите письменное согласие (система не распознаёт тех, у кого нет галочки) и сообщите студентам и преподавателям о съёмке.
